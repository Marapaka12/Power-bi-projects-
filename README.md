**HR Analytics Dashboard | Power BI**

Developed an interactive HR Analytics Dashboard in Power BI to analyze employee data and workforce trends. The dashboard provides insights into employee attrition, department-wise performance, gender distribution, job satisfaction, employee demographics, and retention metrics. Implemented data cleaning, transformation, and DAX calculations to create meaningful KPIs and visualizations, enabling data-driven HR decision-making.
