# 📊 PeoplePulse: HR Analytics & Workforce Attrition Dashboard

An end-to-end Business Intelligence project that transforms raw, unorganized human resources data into an executive-level interactive dashboard. This system tracks key organizational health vectors, identifies employee turnover risk factors, and monitors diversity metrics to support data-driven talent management.

### 🚀 Project Repository Includes
* **Power BI File (`.pbix`):** Complete interactive dashboard layout, relational data model, and visual interfaces.
* **Data Sources:** Sanitized corporate HR datasets (employee profiles, performance metrics, exit indicators).
* **DAX Scripts:** Portfolio of custom formulas used for dynamic KPI cards and demographic breakdowns.

### 🛠️ Key Features
* **ETL & Data Sanitization:** Processed multi-source workforce data via Power Query—handling sensitive missing data, normalizing text fields, and protecting employee anonymity.
* **Relational Data Modeling:** Developed an optimized Star Schema model connecting fact tables (active employee records, status updates) with dimensional lookups (departments, demographics, calendar).
* **Advanced People Analytics:** Wrote custom DAX expressions to isolate compound variables like active attrition speed, satisfaction-to-turnover correlation matrices, and tenure benchmarks.
* **Executive-Level Visualizations:** Structured clean, multi-page layouts focusing on **Attrition Drivers**, **Diversity & Inclusion Tracking (Gender/Age)**, and **Departmental Performance vs. Job Satisfaction**.

### 🧰 Tech Stack & Tools
* **BI Platform:** Power BI Desktop
* **Data Transformation Engine:** Power Query (M Language)
* **Analytical Calculations:** DAX (Data Analysis Expressions)
* **Data Source Ingestion:** Microsoft Excel / CSV

* **ETL & Data Architecture:** Processed multi-source transactional data via Power Query—handling missing transaction entries, removing anomalies, normalizing data types, and building a dedicated custom calendar lookup table.
* **Star-Schema Modeling:** Developed an optimized relational data model to link high-frequency fact tables (sales details) with dimensional lookups (products, customers, regions, dates).
